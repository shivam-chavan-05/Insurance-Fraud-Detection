# Insurance Fraud Detection

## Overview
This project implements a machine learning pipeline to detect fraudulent insurance claims. The system uses various ML models and includes comprehensive data analysis steps:
- Data preprocessing
- Exploratory Data Analysis (EDA)
- Model training and evaluation

## Project Structure
Extract `Insurance_Fraud_detection.zip` to set up the project. The directory structure should be:

```
Insurance_Fraud_detection/
├── Data/
│   └── fraud_oracle.csv
├── data_preprocessing.ipynb
├── modeling_smote.ipynb
├── descriptive_analysis.ipynb
├── EDA.ipynb
├── modeling.ipynb
└── requirements.txt
```

## Prerequisites
- Python 3.11.5
- Visual Studio Code (recommended IDE)
- Required Python packages

## Installation

There are two ways to install the required packages:

1. Using Jupyter notebook:
   ```python
   # Run this in descriptive_analysis.ipynb
   %pip install -r requirements.txt
   ```

2. Using terminal:
   ```bash
   pip install -r requirements.txt
   ```

## Usage

Execute the notebooks in the following sequence:
1. data_preprocessing.ipynb
2. EDA.ipynb
3. descriptive_analysis.ipynb
4. modeling_smote.ipynb
5. modeling.ipynb
